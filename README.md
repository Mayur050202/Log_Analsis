Modern enterprise computing environments generate vast volumes of unstructured log records daily, introducing massive indexing storage overhead and cognitive alert fatigue for security operations centers (SOC). Traditional intrusion detection systems (IDS) rely heavily on deterministic, signature-based rule filtering, rendering them incapable of capturing novel, zero-day threat patterns or structural log mutation shifts. Furthermore, classical SIEM architectures mandate complex, high-overhead relational or document database systems (e.g., SQL, Elasticsearch), creating major ingestion throughput bottlenecks at the network edge. 

To resolve these architectural limitations, this thesis presents an autonomous, highly performant hybrid anomaly engine that operates entirely on a flat-file, database-free architecture. By streaming raw log files directly into volatile memory (RAM) and structuring them via vectorized data frames, the pipeline completely eliminates database indexing latencies. The core detection engine leverages Natural Language Processing (NLP) via Term Frequency-Inverse Document Frequency (TF-IDF) Vectorization paired with an Unsupervised K-Means Clustering Algorithm. Instead of relying on hardcoded human criteria, the engine maps text strings into multi-dimensional spatial coordinates and utilizes Euclidean distance calculations to isolate statistical outliers at a strict 99.9th percentile threshold. 

The framework was rigorously validated through a simulated live chaos engineering injection sequence against an academic HDFS log baseline. The pipeline achieved a verified **100.00% F1-Score system accuracy validation metric**, automatically detecting incoming streaming exploits—including botnet saturation and privilege mutations—while dynamically extracting target threat actor IP vectors via localized Regular Expressions (Regex). The system renders results through an integrated Streamlit web dashboard interface, compiling actionable runbooks and automated incident reports, proving that enterprise-grade AI threat isolation can be executed efficiently on lightweight edge infrastructure.
